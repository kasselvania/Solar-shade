# Security and Safety Reporting

Solar Shade is pre-prototype hardware and software.

Do not use a public issue to disclose:

- exploitable device credentials;
- private broker endpoints;
- home address or precise location;
- personal network topology;
- private photographs;
- a reproducible safety defect in an installed unit that would expose a household before mitigation.

For now, contact the repository owner through their GitHub profile with a minimal description that does not include secrets. A dedicated security contact may be added later.

Public issues are appropriate for:

- already-sanitized design concerns;
- component errata;
- non-sensitive state-machine defects;
- documentation errors;
- reproducible test failures with no personal data.

No release in this repository is currently certified or qualified for unattended consumer use.
